# My Shopping Helper

Type what you need once, then check every store you shop at, with one list for all of them.

- 24 stores in 5 groups: everything stores (Amazon, Walmart, Target, Costco, Sam's Club), groceries
  (Kroger, H-E-B, Whole Foods, Sprouts, Aldi, Albertsons, Tom Thumb, Trader Joe's, Instacart),
  furniture and home (Wayfair, Ashley, Rooms To Go, IKEA), dollar and discount (Dollar Tree,
  Dollar General, Family Dollar, Five Below), and pharmacy (Walgreens, CVS).
- Choose "my stores" to show first; the rest stay under "More stores".
- Each store button opens that store's own search, so prices and stock are always current.
- One shopping list (free), saved on the phone, with store buttons on every item.

Premium (through CashCow, $1.99/mo, $14.99/yr or $29.99 once): more lists, price notes with the
best value per ounce or per item, and restock reminders. One CashCow account works in every CashCow app.

Stores live in `brand.js`. To earn from a store, add its affiliate tracking link there.

## Render (Static Site)
- Build command: `npm install && npm run build`
- Publish directory: `dist`
